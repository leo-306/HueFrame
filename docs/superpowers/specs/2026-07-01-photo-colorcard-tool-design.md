# HueFrame —— 照片色卡拼贴工具需求分析与设计思路

## 产品定位

一个功能全面的本地处理照片色卡工具：上传照片，自动提取主色调，生成多种风格的色卡拼贴图。核心技术立场是纯前端、无后端、隐私友好、不做需要模型能力的智能化功能。

## 基线能力（MVP）

1. **取色引擎**：照片缩图（约 120px）→ 量化分桶 → 合并相近色按占比排序 → 得到主色调列表。
2. **地点识别**：优先读取照片 EXIF 中的 GPS 坐标反查地名；无坐标时用当前网络 IP 定位兜底。
3. **拍摄时间**：从 EXIF 读取拍摄时间，自动填入卡片副标题。
4. **滤镜**：多种胶片/相机风格滤镜（模拟不同相机品牌的近似发色曲线）。
5. **色名系统**：主色自动匹配中文色名（如绯樱、橄榄、群青），支持中英对照切换。
6. **版式与导出**：多套版式模板、多款标题字体、多尺寸导出。

技术约束：**零后端**，图片全程在浏览器本地处理，不上传服务器；EXIF 手写解析（JPEG 走 APP1 段，HEIC 扫 Exif 标记复用 TIFF 解析）；HEIC 解码库按需加载；文字色自动取与背景 WCAG 对比度最大的颜色，保证可读性；无需注册、免费、无登录墙。

## 扩展模块

在基线之上按优先级排列，具体做哪些由后续实现阶段取舍。

### V2 优先级 A：多平台导出适配

覆盖导出场景：

| 场景 | 建议比例/规格 |
|---|---|
| 小红书 / 朋友圈 | 3:4、1:1 |
| 公众号头图 / 抖音配图 | 2.35:1 长图（公众号头图）、9:16（抖音故事图/配图） |
| Instagram | 1:1、4:5 |
| 打印 / 实体周边（明信片、海报、相册） | 300dpi 高清导出，A4、6 寸、明信片标准尺寸预设，含出血位处理 |

实现思路：一套设计稿 + 比例裁切/重排规则，而非每个平台单独设计版式，降低维护成本。

### V2 优先级 B：更多版式与素材玩法

#### 风格分类框架

按视觉风格划分版式类别，覆盖不同内容调性：

| 风格 | 特点 | 适用内容 |
|---|---|---|
| 潮酷风 | 块状构图，视觉冲击力强 | 穿搭、街拍 |
| 拼贴风 | 画面丰富、故事性强 | 日常记录、美食、旅行 |
| 扁平风 | 对称/网格布局，整齐规整 | 知识分享、干货图解 |
| 时尚风 | 留白节奏感、高级感 | 美妆教程、护肤测评、杂志封面感 |
| 实景风 | 真实拼接、代入感强 | 家居、健身、摄影 |
| 工具向 | 色号编码、色块编号排版、大留白构图 | 设计师/开发者向专业色卡展示 |

#### 展示样式扩展点

- **经典色带/色卡条**：色块等分横向/竖向排列，每块标注 HEX 值，风格极简工具感
- **渐变色带版式**：主色调做成平滑渐变过渡，而非离散色块，适合壁纸类场景
- **场景应用预览版式**：用提取出的配色即时套用到一个简化的示意场景（如穿搭色块示意、房间配色示意），让色卡"可视化落地"而不只是抽象色块
- **工具向色卡版式**：同时展示 HEX / RGB / HSB 多种色彩空间数值，面向设计师/开发者用户的专业风格
- **拼贴组合版式**：照片原图与色卡色块直接拼贴在同一构图里，而非分区展示
- **意境标题命名**：给整套配色取一个场景化标题（而非只给单色起名），如自动根据地点+色调生成"清晨的圣托里尼"这类标题
- **拼贴类素材**：胶片贴纸、地点定位贴纸、手写体日期戳，作为可选叠加图层
- **新增排版方向**：横向长图（适配公众号头图）、竖向故事图（抖音 9:16）、方形网格（Instagram）
- **背景/边框素材**：纹理背景（纸纹、胶片颗粒）、相框边框样式

实现思路：版式抽象为可配置布局模板（色块位置、文字区、图片区参数化），新增版式只需加配置，不需要新写渲染逻辑；素材层（贴纸/纹理/边框）与主版式解耦，作为独立可选叠加层。

### V3：多图/网格拼贴玩法

- 多图上传后，生成统一色调的四宫格/九宫格拼贴——对每张图分别取色后，计算全局调色板做加权合并，让网格内色彩呼应而不生硬统一
- 一图切多图：支持九宫格（3×3）、自定义 N×M 网格、长图分镜（1×N）三种切法，自动识别长图分隔区域，也支持手动拖动切线微调；补充统一滤镜/画框，保持切片视觉一致；切片本地打包成 ZIP 导出
- **网格间距设置**：切片之间可留出可调间隙（gutter）而非严丝合缝拼接，适配需要"呼吸感"的排版场景；间距区域可选填充色（如背景色、主色调之一）
- 多图色板汇总卡：从一组照片提取出一条"色彩时间线"

优先级低于 A/B 的原因：需要新的多图状态管理和联动取色算法，复杂度明显高于单图流程的模板扩展。

## 明确不做的部分

- 不做登录、账号系统、云端保存
- 不做 AI 智能推荐版式、智能选图等依赖模型能力的功能——保持纯前端静态处理的技术定位
- 视觉设计、页面结构、文案风格完全自主设计
